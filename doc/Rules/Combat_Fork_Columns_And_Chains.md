# 분기안: 보드 배열·열 더미·연쇄 공격

갱신: 2026-10-17. 이 문서는 원안과 별도로 탐색 중인 전투 구상을 기록한다. 원안을 대체하기로 결정하지 않았다. 숫자는 규모와 관계를 설명하는 임의의 예시이며 구현·밸런스 확정값이 아니다.

## 1. 원안과 분기안의 구분

사용자는 기존 비공개 카드 추론·장착 스킬 투자 구상을 **원안**, 보드 배열·손패 맞교환 구상을 **분기안**으로 부르기로 했다.

원안은 손패와 보드를 합쳐 스킬 조건을 판정한다. 분기안의 출발점은 보드 카드의 순서·배열로 효과를 정하고, 손패는 보드와 맞교환하는 재료로 사용하는 것이다. 분기안에서도 베팅의 재미를 결합할 가능성을 검토했으나, 베팅 대상과 범위를 확정하지 않았다.

## 2. 첨부 문서에서 출발한 배열·맞교환 구상

사용자가 Gemini와 논의해 첨부한 문서의 구상:

- 보드의 카드 배열과 순서로 조합·효과를 판정한다. 손패는 판정에 직접 합산하지 않는다.
- 전체 카드가 모두 하나의 조건을 만족해야 하는 것은 아니며, 부분 조합과 인접·순서 조건을 함께 고려한다. 구체적인 문법은 미정이다.
- 손패와 특정 보드 위치의 카드를 일대일 맞교환한다. 넣는 카드와 위치를 함께 선택한다.
- 보드의 기본 공개 정보량을 늘린다. 전부 공개한다고 확정한 것은 아니다.
- 액션 단계 종료 시 항상 공격·효과가 발생하는 구상이다. 조건이 없을 때의 기본 효과는 미정이다.
- 적의 위치 교란을 예고해, 먼저 처치하거나 교란을 고려한 배열로 대응하는 방향이다. 코인에 따른 선공과 판정 시점은 연결이 필요하다.

위 내용은 첨부된 분기안의 출발점이다. 이후 열 더미·연쇄와 결합할 때 손패 맞교환, 공개 범위, 상시 공격 등을 모두 그대로 유지한다고 확정한 것은 아니다.

## 3. 열 더미 구조

하나의 덱에서 보드 몇 장을 뽑아 놓는 대신, 섞인 덱을 여러 열로 균등하게 나누어 쌓는 발상이다. 예시로 40장을 다섯 열에 나누면 각 열에 여덟 장이 놓인다. 와일드 포함 시 배분 등 세부 규칙은 미정이다.

에이전트가 설명용으로 제안한 임시 용어:

| 임시 용어 | 의미 |
| --- | --- |
| 열 | 보드의 좌우 위치 |
| 열 더미 | 그 열에 쌓인 카드들 |
| 활성 카드 | 현재 조합 판정에 쓰이는 각 열의 맨 위 카드 |

사용자가 용어를 확정한 것은 아니다. 각 열의 최상단 카드가 이루는 좌우 배열로 조합을 판단한다.

### 셔플과 열 사이 이동

사용자가 명시한 조건:

- 일반적인 카드 섞기는 **열 내부에서만** 가능하다.
- 특별한 스킬로 다른 열 사이의 카드를 교환할 수 있다.
- 열 사이 교환은 자주, 정기적으로 또는 필수적으로 발생하는 행동이 아니다.

기존 손패 맞교환을 열 더미 구조에 어떻게 적용할지는 별도로 연결해야 한다. 일반 맞교환을 통해 열 사이 이동 제한을 자동으로 우회할 수 있다고 가정하지 않는다.

## 4. 정보가 남는 이유

Gemini는 카드를 확인한 뒤 섞이거나 아래로 내려가도 '어느 열 안에 특정 카드가 있다'는 정보는 남는다고 설명했고, 사용자는 이 부분에 공감했다.

- 정확한 깊이·순서에 대한 정보와 열의 구성에 대한 정보는 구분된다.
- 열 내부 셔플은 정확한 순서를 바꿔도 그 열의 카드 구성을 유지한다.
- 열 사이 이동 등 구성 변화가 없으면, 확인한 카드가 그 열에 있다는 지식을 계속 활용할 수 있다.
- 따라서 확인 정보는 이번 공격의 성공 여부뿐 아니라 이후 어느 열에 개입할지를 판단하는 근거가 될 수 있다.

정확한 카드 순서·위치를 기억해야 하는 부담을 어떻게 줄일지는 미정이다. 확인한 정보를 게임이 기록해 주자는 의견은 에이전트의 제안이며 채택된 규칙이 아니다.

## 5. 최신 탐색안: 카드 순환에 따른 연쇄 공격

사용자는 여러 라운드 동안 카드 보기·이동·셔플 등을 통해 다음 카드를 알거나 준비한 뒤, 선택한 여러 스킬을 연결하는 구상을 제시했다.

### 사용자 예시

이번 라운드에 세 가지 스킬을 선택했다고 가정한다. 예시에서는 그중 원페어와 스트레이트의 연결을 설명했으며 세 번째 스킬은 지정하지 않았다.

| 단계 | 각 열의 최상단 배열 | 처리 |
| --- | --- | --- |
| 시작 | `1 · 2 · 9 · 9 · 5` | 첫 번째 원페어 스킬이 두 장의 9로 발동 |
| 사용 카드 이동 | 두 9가 각각 자신이 속한 열의 맨 아래로 이동 | 그 아래에 있던 3과 4가 공개됨 |
| 다음 배열 | `1 · 2 · 3 · 4 · 5` | 선택한 다른 스킬인 스트레이트가 발동해 2연쇄 공격 |

사용자는 이전 라운드의 조작으로 두 9 아래에 3과 4가 오도록 준비했거나, 이미 그 정보를 알고 있었던 상황을 설명했다. 구체적인 이동 액션과 비용은 아직 정의하지 않았다.

### 이 예시에서 읽을 수 있는 의도

- 스킬에 사용된 카드가 내려가면서 보드가 바뀌고, 새 배열이 다음 스킬의 조건을 만든다.
- 지금 스킬의 피해뿐 아니라, 그 스킬이 어떤 카드를 치워 다음 배열을 여는지가 중요해진다.
- 정보 수집과 준비의 성과를 결과 단계의 연속 공격으로 연결하려 한다.
- 예시의 '카드 소모'는 카드를 해당 열 아래로 보내는 순환이다. 영구 파괴나 스킬 카드 내구도 차감과 동일시하지 않는다.
- 연쇄 자체에 별도 피해 배율·추가 보너스가 있다고 가정하지 않는다.

### 아직 정하지 않은 처리

- 선택한 스킬의 실행 순서를 직접 지정하는지, 자동 순서가 있는지.
- 앞에서 조건 불충족으로 실패한 스킬을 배열 변화 후 다시 검사하는지.
- 같은 스킬이 한 결과 단계에서 반복 발동할 수 있는지, 연쇄 종료 조건은 무엇인지.
- 페어 등이 여러 묶음일 때 어떤 카드를 사용할지 직접 선택하는지.
- 스킬별로 사용 카드 전부가 내려가는지, 여러 카드를 같은 열에서 이동시키는 경우의 순서는 어떤지.
- 매 이동마다 맨 위 카드를 공개하는지, 결과 단계 이후 공개 정보가 유지되는지.
- 공격·회복·방어의 연쇄, 적의 개입 시점, 대상이 먼저 처치되었을 때 후속 스킬 처리.
- 원안의 코인 비용·실패 소모·쿨타임·모험 내구도를 어느 범위까지 이어받는지.
- 라운드 종료 시 추가 폐기·보존을 하는지. 원안의 보존 규칙을 자동 적용하지 않는다.

원안에서는 한 카드가 여러 스킬의 조건을 동시에 만족시켰다. 최신 예시는 사용 카드가 내려가므로 이후 스킬이 보는 배열이 달라진다. 두 방식의 관계를 정해야 하며 원안의 중복 활용을 그대로 적용하지 않는다.

## 6. 남겨 둔 후보와 폐기한 제안

### 후보: 조합 라운드·랜덤 라운드 교대

사용자는 배열을 다듬는 라운드와 무작위 변화를 주는 라운드를 교대로 적용하고, 스킬로 다음 라운드 종류를 바꿀 가능성을 제안했다. 이후 반드시 이렇게 나눌 필요는 없으며 순간적인 영감 중 하나라고 설명했다. **검토 가능한 후보로 보존하되 열 더미·연쇄의 필수 전제로 삼지 않는다.**

에이전트가 제시한 내부 셔플, 최상단을 아래로 보내 다음 카드 노출, 일부 열만 갱신하는 방식은 이때의 검토 후보였다. 이를 모두 채택한 갱신 규칙으로 취급하지 않는다. 이후 사용자가 제시한 사용 카드의 하단 이동은 위 연쇄 예시의 내용이다.

### 폐기: 각 열의 임의 층 직접 선택

사용자는 각 열에서 원하는 깊이의 카드를 골라 공격하고 되돌린 뒤 위치를 기억하는 방식을 잠깐 제안했다. 기억력 게임이 될 것 같다며 직접 폐기했다.

**폐기 대상은 임의 층 선택 방식이다. 열 더미, 열 구성에 대한 정보, 준비한 순서로 연쇄하는 발상까지 폐기한 것은 아니다.**

## 7. 에이전트 검토 — 사용자 결정과 구분

- 첫 공격이 다음 배열을 여는 역할을 가지므로 저위력 스킬도 연결 수단으로 가치가 생길 수 있다.
- 카드를 고정해 좋은 배열을 유지하는 것 외에, 좋은 배열을 사용해 다음 배열로 넘어가는 재미를 만들 가능성이 있다.
- 계획된 연쇄와 일부 정보만으로 노리는 연쇄가 공존할 여지가 있다. 실제 재미와 균형은 검증하지 않았다.
- 실행 순서, 사용 카드 선택, 이미 본 정보의 표시가 플레이어 통제감에 큰 영향을 줄 것으로 본다.
- 연쇄를 위해 항상 같은 열만 순환시키거나 같은 스킬 순서를 반복하는 구성이 생기는지는 스킬·코인·쿨타임·내구도의 적용 범위가 정해진 후 검토할 수 있다. 현재 확정 결함으로 보지 않는다.

## 8. 추가 탐색 가능성: 보드게임

사용자는 잘 설계하면 보드게임으로도 만들 수 있을 것 같다는 가능성을 제기했다. 실물 게임 제작을 결정하거나 현재 개발 목표를 전환한 것은 아니다.

에이전트는 열 더미·사용 카드의 하단 이동·다음 카드 공개가 실물로 표현하기 쉬운 요소라고 보았다. 실제 전환 시에는 여러 스킬의 조건 판정, 쿨타임·내구도 기록, 비공개 정보 관리가 사람에게 주는 부담을 검토해야 한다. 이는 초기 의견이며 실물 플레이 검증 결과는 아니다.
